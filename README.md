𝕿𝖍𝖊 𝕸𝖆𝖓𝖎𝖋𝖊𝖘𝖙𝖔 📜  
B.Sc in Computer Science and infinite curiosity guides me through blending robust systems engineering with immersive aesthetics. My work spans the technological spectrum, bridging low-level architecture with modern interactive media. Stay tuned to see them published soon!  
𝕮𝖚𝖗𝖗𝖊𝖓𝖙 𝕺𝖕𝖚𝖘: 𝕻𝖆𝖗𝖆𝖌𝖔𝖓 🎮
